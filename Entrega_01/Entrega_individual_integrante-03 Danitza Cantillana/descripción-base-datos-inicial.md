### 2) Base de datos existente

El **Instituto Nacional de Estadísticas (INE)** elaboró en 2019 el estudio *Indicadores de calidad de plazas y parques urbanos en Chile*, que permite analizar distintos espacios públicos del país. La base de datos registra información sobre el equipamiento, accesibilidad, seguridad, vegetación y mantención de plazas y parques urbanos, además de asignar un rango de calidad a cada espacio evaluado. Para esta investigación se utilizará exclusivamente la información correspondiente a la **Región Metropolitana**, con el objetivo de comparar las condiciones de las plazas y parques de las comunas seleccionadas.

**Autor y publicación de los datos:** Instituto Nacional de Estadísticas (INE), específicamente el Subdepartamento de Geografía. Los datos corresponden al estudio *Indicadores de calidad de plazas y parques urbanos en Chile 2019*, publicado por el INE a partir de un levantamiento realizado durante 2019.

**Contenido:** La base contiene información de plazas y parques urbanos, identificando donde pertenece cada espacio. Entre las variables registradas se encuentran características de acceso, equipamiento, infraestructura deportiva, baños, condiciones de accesibilidad, aspectos de seguridad y limpieza. Finalmente, cada plaza o parque cuenta con un rango de calidad asignado de acuerdo con las categorías establecidas por el estudio.

**Pertinencia:** Esta base permite incorporar una dimensión específica de la calidad de vida relacionada con el entorno urbano y los espacios públicos. Su información permitirá comparar las condiciones de las plazas y parques de las comunas seleccionadas y determinar si existen diferencias en los aspectos antes mencionados. Además, al contar con información asociada a cada espacio, los datos pueden ser utilizados para representar geográficamente la distribución de la calidad de estos espacios públicos dentro de la Región Metropolitana.

**Metodología:** Los datos fueron levantados por el INE durante 2019 mediante la evaluación de plazas y parques urbanos a partir de una pauta estandarizada. Se registraron las características físicas, de equipamiento, accesibilidad, seguridad, vegetación y mantención de cada espacio. A partir de estas variables se establecieron indicadores y un rango de calidad para las plazas y parques evaluados.
